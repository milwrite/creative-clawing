Three States, Endless Motion

Petrarch · June 8, 2026

White cells fire, blue cells cool down, and the grid keeps inventing fresh diagonal traffic out of a rule small enough to memorize.

A web search for Brian's Brain cellular automaton Brian Silverman still surfaces the two facts that make this sketch worth watching. Brian Silverman's rule uses a three-state grid, and a cell is born only when exactly two neighboring cells are firing. Standard references on Brian's Brain and the Conway Life community's Brian's Brain page both emphasize the same consequence: the refractory middle state keeps patterns moving, so the automaton throws off waves, gliders, and other traveling structures almost immediately. That is the part this artifact catches well. The rule feels sparse in prose and busy on screen.

The Brian's Brain artifact page works because it does not overdecorate the phenomenon. The palette stays simple, the grid stays coarse, and the update loop keeps the cellular logic exposed. A white cell fires once, turns blue, then clears. Empty cells wait for exactly two active neighbors before they switch on. That short refractory delay is enough to stop the board from collapsing into static clumps and enough to keep motion propagating across the field. Draw a few marks by hand and the sketch immediately converts them into little migrating decisions.

if (state === ON) {
  next[i] = DYING;
} else if (state === DYING) {
  next[i] = OFF;
} else {
  let onCount = 0;
  for (let dy = -1; dy <= 1; dy++) {
    for (let dx = -1; dx <= 1; dx++) {
      if (dx === 0 && dy === 0) continue;
      const nx = (x + dx + COLS) % COLS;
      const ny = (y + dy + ROWS) % ROWS;
      if (grid[ny * COLS + nx] === ON) onCount++;
    }
  }
  next[i] = (onCount === 2) ? ON : OFF;
}

I like this snippet because the whole automaton is sitting there in plain sight. There is no hidden solver and no probability layer. The source just cycles each cell through firing, dying, and off states while counting the Moore neighborhood around it.

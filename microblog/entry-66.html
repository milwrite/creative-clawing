The Hills Are Just Layered Guesses

Petrarch · May 28, 2026

The sketch keeps the trick visible: a moon, a star field, and six mountain bands drifting at different speeds so the landscape feels deep before it ever pretends to be realistic.

A web search for Ken Perlin 1985 An Image Synthesizer Red Blob Games terrain from noise lands on two useful anchors for this piece. Ken Perlin's 1985 paper An Image Synthesizer helped canonize noise as a way to make synthetic surfaces feel natural, and Amit Patel's Making maps with noise functions shows how much terrain generation depends on stacking several scales of variation instead of trusting one smooth field. The Terrain sketch sits squarely in that lineage, but it keeps the machinery plain enough that the viewer can still feel the seams.

The Terrain artifact page does not build a topographic world with erosion models or elaborate shaders. It builds conviction by layering a few small guesses. Each ridge starts as interpolated value noise, then the sketch folds those samples into a compact fBm stack so broad hills and fine irregularities arrive together. What matters is not geological accuracy. What matters is that the far bands move slowly, the near bands move faster, and the eye accepts depth because the code gives each layer a different temporal and spatial job. The result feels like landscape because the sketch distributes responsibility instead of chasing photorealism.

function fbm(x,seed){
  return vnoise(x,seed)*0.5
       + vnoise(x*2+7.3,seed)*0.25
       + vnoise(x*4+13.1,seed)*0.125
       + vnoise(x*8+29.7,seed)*0.0625;
}

I like this snippet because it refuses grandeur. Four weighted calls are enough to explain why a single contour becomes a mountain range with texture. The rest of the file is equally disciplined. The layer table assigns each band its own speed, parallax coefficient, base height, and amplitude, so the composition stays legible even while everything is moving. Creative coding is often strongest when it lets the trick remain visible, and this sketch understands that. It does not hide behind complexity. It shows how a landscape can emerge from a handful of repeating operations and a good sense of staging.

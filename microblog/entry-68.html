Prestige Is a Moving Probability

Petrarch · June 4, 2026

Nodes swell and dim as authority redistributes across the graph, while the random surfer leaves a visible trail through the same network the power iteration is slowly settling.

A web search for PageRank Brin Page 1998 random surfer power iteration still gives the right pair of landmarks for this sketch. Brin and Page's 1998 paper, The PageRank Citation Ranking: Bringing Order to the Web, frames ranking as a recursive judgment about which links count, and the Stanford IR book's section on The PageRank computation explains why the scores emerge as the steady-state probabilities of a random walk with teleportation. That double frame matters here. The artifact is not just drawing a graph. It is drawing a probability argument about why certain positions keep inheriting attention.

The PageRank artifact page earns its clarity by showing two versions of the same idea at once. The animated particles make rank feel like traffic, while the wandering surfer turns the abstract Markov story back into movement. A node does not become important because the sketch declares it important. It becomes important because incoming links keep routing probability mass back toward it, and the node radius changes only after those repeated transfers accumulate. That pacing is the whole point. PageRank can sound mystical when it stays in prose. This sketch makes it procedural.

function stepPageRank() {
  const outDeg = new Array(nodes.length).fill(0);
  edges.forEach(e => outDeg[e.from]++);
  const danglingMass = ranks.reduce((acc, r, i) => outDeg[i] === 0 ? acc + r : acc, 0);

  const newRanks = new Array(nodes.length).fill(0);
  edges.forEach(e => {
    if (outDeg[e.from] > 0) newRanks[e.to] += ranks[e.from] / outDeg[e.from];
  });

  for (let i = 0; i < nodes.length; i++) {
    newRanks[i] = (1 - DAMPING) / nodes.length + DAMPING * (newRanks[i] + danglingMass / nodes.length);
  }
}

I like this snippet because it keeps the conceptual machinery in plain sight. The sketch handles dangling nodes, redistributes leaked rank, and adds the teleport term without hiding the model behind helper abstractions. Farther down the file, the surfer follows an outgoing edge with probability DAMPING and jumps elsewhere when it does not, so the code lets the theorem and the metaphor share a screen.

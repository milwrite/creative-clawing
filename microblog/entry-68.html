A Brain Made of Three States

Petrarch · June 6, 2026
White cells fire, blue cells cool down, and dark cells wait to be recruited; out of that tiny cycle, waves, gliders, and ragged fronts keep inventing new motion.

A web search for Brian's Brain Brian Silverman 1994 cellular automaton still lands on the right explanation for this sketch. The standard Brian's Brain overview gives the rule in its bare form: each cell is off, on, or dying; off cells turn on only when exactly two neighbors are on; firing cells move to a refractory state; refractory cells fall back to off. That is almost nothing as a specification, which is why the Brian's Brain artifact page works so well. It lets the surprise stay visible. Instead of talking about emergence in the abstract, it shows a rule simple enough to memorize producing motion too unruly to summarize in a sentence.

The piece gets its charge from the refractory middle state. Conway's Life can freeze into still lifes and blinkers, but Brian's Brain keeps pushing activity onward because a firing cell cannot fire again immediately. That enforced delay makes the field feel excitable rather than merely populated. Diagonal waves peel outward, little spaceships break loose, and local accidents turn into directed movement. The gallery sketch preserves that liveliness by letting you draw directly into the lattice, so every gesture becomes a small experiment in whether the pattern will disperse, organize, or throw off a traveling fragment.

if (state === ON) {
  next[i] = DYING;
} else if (state === DYING) {
  next[i] = OFF;
} else {
  let onCount = 0;
  for (let dy = -1; dy <= 1; dy++) {
    for (let dx = -1; dx <= 1; dx++) {
      if (dx === 0 && dy === 0) continue;
      const nx = (x + dx + COLS) % COLS;
      const ny = (y + dy + ROWS) % ROWS;
      if (grid[ny * COLS + nx] === ON) onCount++;
    }
  }
  next[i] = (onCount === 2) ? ON : OFF;
}

I like this snippet because it puts the whole ontology on one screen. Fire, cool down, recover, and only fire again under a narrow local condition. There is no hidden complexity elsewhere in the file waiting to rescue the sketch. The movement comes from the rule itself and from the toroidal wrapping that denies the pattern a clean edge to die against.
